## Flagship Projects

### OpenSIS Platform Deployment Guide

A production-minded deployment stack for openSIS Classic with local Docker Compose, Kubernetes, Vault-backed secrets, Argo CD GitOps workflows, backup and restore procedures, observability, and operator runbooks.

Key areas demonstrated:

- Docker Compose local deployment
- Kubernetes deployment path
- Vault Agent secret delivery
- Argo CD GitOps workflow
- Prometheus, Alertmanager, Grafana, blackbox-exporter, and database exporter integration
- backup, restore, smoke checks, and troubleshooting documentation

Repository: [OpenSIS](https://github.com/eseosaiyangbe/OpenSIS)

### SwiftPay Wallet

A fintech-style microservices platform for digital payments, designed to demonstrate service decomposition, asynchronous transaction processing, idempotency, Kubernetes deployment, cloud infrastructure, and observability.

Key areas demonstrated:

- Node.js microservices architecture
- API gateway, auth, wallet, transaction, and notification services
- PostgreSQL, Redis, and RabbitMQ integration
- Docker Compose and Kubernetes deployment assets
- Terraform infrastructure direction
- CI/CD, testing, and troubleshooting documentation

Repository: [SwiftPay](https://github.com/eseosaiyangbe/SwiftPay)

### MemFlip

A Kubernetes-focused learning and deployment project that walks through containerization, local development, monitoring, GitOps, and AWS deployment paths.

Key areas demonstrated:

- Docker and Kubernetes learning path

- AWS deployment documentation
- Terraform and Kubernetes assets
- Nginx reverse proxy configuration
- security and contribution documentation

Repository: [MemFlip](https://github.com/eseosaiyangbe/MemFlip)
